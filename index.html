Cài đặt thành App trên Android

Mở qua link HTTPS trên Chrome để ghim màn hình chính

  1. Mở trang Coffee Tracking bằng Google Chrome (khuyên dùng link https://).
  2. Nhấn biểu tượng Dấu ba chấm (⋮) ở góc trên bên phải màn hình.
  3. Chọn "Thêm vào màn hình chính" hoặc "Cài đặt ứng dụng".
  4. Nhấn Thêm để mở nhanh từ màn hình chính Android.

🔄 Xuất & Đồng bộ File Backup (Laptop ↔ Android)

Hãy Xuất file Backup (.json) trên máy nguồn, gửi sang máy đích, sau đó chọn chế độ đồng bộ và Nạp file Backup để khôi phục & đồng bộ dữ liệu.
